# Codexa Scanner Documentation

Codexa Scanner is a bounded, non-exploitative desktop assessment tool. Use it only against systems you own or are explicitly authorized to assess.

## Guides

- [User Guide](user-guide.md) — installation, first run, workflow, and troubleshooting.
- [Port Scanner](port-scanner.md) — bounded TCP scanning, target validation, scope confirmation, and cancellation.
- [Web Audit](web-audit.md) — passive HTTP/HTTPS checks, findings, redirects, and private/lab access.
- [Subdomain Discovery](subdomain-discovery.md) — Certificate Transparency results and optional DNS wordlist checks.
- [Path Fuzzer](path-fuzzer.md) — bounded HEAD-only path checks and catch-all filtering.
- [TLS Inspector](tls-inspector.md) — certificate details and legacy TLS probe interpretation.
- [DNS Intelligence](dns-intelligence.md) — DNS records, PTR, and optional RDAP metadata.
- [IP Information](ip-information.md) — source-labeled address classification, PTR, and public-IP RDAP metadata.
- [History and Reports](history-and-reports.md) — local retention, port diffs, and exports.
- [Release & Installer Verification (v1.1.0)](release-verification.md) — CI release workflow, v1.1.0 `.deb`/`.exe` assets, and clean-machine install/upgrade/uninstall checks.

Each feature page documents what the module does, what it does not do, and how to interpret its output.
